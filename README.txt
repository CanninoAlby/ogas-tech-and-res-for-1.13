接下来我介绍一下如何为新的大型模组做OGAS适配。
简单来说，OGAS框架已经有了。我们只需要修改让OGAS知道有什么商品，有什么生产方式，即可。
也就是说，只需要更新商品信息、建筑信息、生产方式信息、生产方式组信息，即可成功适配。
只需要做这样几步：
1.将原版和mod当中的所有商品信息、建筑信息、生产方式信息、生产方式组信息进行整合。
2.将这些内容放入到Victoria3 building PM当中相应文件夹。并运行main.py，生成新的csv文件。
3.在csv当中，删除掉不需要OGAS进行操作的行。比方说奇观、政府建筑、庄园宅邸等。
4.在csv当中，将所有生产方式的type改为upgrade或者balance。切记！否则OGAS不会调整它们的生产方式。
5.将商品信息放入到OGAS script generator当中相应文件夹（没有新商品就不用放）。将修改后的csv放入到OGAS script generator目录下。然后运行main.py。
6.将所有script开头的文件夹，以及journal_entries文件夹当中生成的内容，替换掉原来common/下相同路径的同名文件。
7.如果添加了新的建筑，记得修改localization的内容。否则新商品的名称不会显示，而是会显示原来的key。注意不要漏掉文件开头的BOM。还有，建议修改关于OGAS的localization，以说明这是专门为某个模组适配的OGAS，并非原版。
